Install on a Mac

Setup checks what is missing and installs it with Homebrew. You sign in to the spare account yourself, in a normal browser window with its own empty profile.

  • macOS with Homebrew and Node 20 or newer
  • Claude Code, signed in
  • Brave, Chrome or Edge
  • A spare Instagram account you can afford to lose
git clone https://github.com/MatijaMiki/reelstoclaude ~/.reelstoclaude
cd ~/.reelstoclaude && npm install && npm link

reelstoclaude setup                 # ffmpeg, yt-dlp, whisper, speech model
reelstoclaude login                 # sign in to the spare account
reelstoclaude owner your_username   # the only account it listens to
reelstoclaude start                 # background helper on

Then DM the spare account a reel from your own account. “reelstoclaude stop” turns it off, “reelstoclaude usage” shows what each reel used.

Read this first

Does Instagram allow this?

No. reelstoclaude drives a normal account in a browser, which is against Instagram’s terms, and that account can get locked. Use a spare one. If Instagram asks to confirm you are human, reelstoclaude stops and shows a Mac notification. It never tries to get past the check.

Does it run code from a reel?

No. A skill is copied in as files and a repo is downloaded; nothing from either is run. Before you say yes, the reply tells you how many scripts a skill contains.

Who can send it reels?

Only you. It reads one chat, the one with your own account, and ignores message requests, follow requests and every other chat.

What leaves my Mac?

Speech is turned into text on your Mac. The caption, the transcript and a few frames go to Claude through your own Claude Code sign-in. There is no reelstoclaude server.

What does it cost?

The tool is free. Each reel uses a little of your Claude plan: about two cents of API-equivalent usage on Haiku in our tests, less for a funny reel. Waiting for messages uses none.

How heavy is it?

It keeps one hidden browser tab open on the Messages page so it can answer within seconds. On our Mac that is about 1 GB of memory.

Windows or Linux?

Not yet. It is built for macOS: Homebrew for the tools and a login item for the background helper.
